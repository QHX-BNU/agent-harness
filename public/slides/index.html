内核

控制循环：模型 → 工具 → 模型一个会话是一个状态机，不是一条裸消息数组

🔁循环里做的事

  • 步数预算、并发 / 串行工具执行
  • 工具调用前后都过策略层与审批
  • 审批挂起时状态变 awaiting_approval
  • 随时中止（abort），并落 trace
  • 超长工具结果落盘，按 turn 裁剪历史

🚦状态机

idle running awaiting_approval aborted error

轮次步数、token 与成本聚合挂在状态上；会话存在磁盘上，重启不丢，可以恢复、可以回放。

✅ allow

读文件、搜索这类安全操作直接放行。

⏳ ask

写文件、执行命令弹审批按钮；超时等于拒绝。

⛔ deny

危险命令硬拦：rm -rf /、mkfs、改注册表等。

长期记忆

记住你，但别把上下文塞爆三块常驻画像 + 三层结构化记忆 + 每轮按预算召回

👤user.md

🫀soul.md

🗂结构化分层

  • global：所有会话可见的长期事实
  • workspace：只在这个工作区生效
  • session：本会话的临时上下文

🔍检索与召回

  • 词元重叠 + 重要度 + 时效打分（零依赖，不建向量库）
  • 每轮自动召回 top-K，按字符预算截断注入
  • 记忆加载有统计：这次对话到底用了哪几条，看得见
安全边界

沙箱：三平台原生轻量边界和 Claude Code / Codex 同款思路 —— 不拉容器、不要 root、不要守护进程

🐧Linux

bwrap：整机只读 + 授权根可写，独立 PID/IPC/UTS namespace

🍎macOS

sandbox-exec（Seatbelt）：deny default，读全域写白名单

🪟Windows

受限令牌 + capability SID ACL + Job Object

🌐网络：三种强制力，绝不假装

内核断网（bwrap --unshare-net / Seatbelt / Docker network none）— 绕不过； 强制代理桥（bwrap 白/黑名单：沙箱里只有一个 unix socket 出口）— 绕不过； 合作式代理（windows / wsl / local）— 会被直连绕过，界面里如实标注。

组件缺失或内核不支持时 失败关闭：直接拒绝执行，绝不静默回落到策略层。

扩展

子代理与工作流把「一个大任务」拆成可并行、可追溯的小任务

🤖子代理（subagent）

  • 独立上下文，不污染主对话
  • 并发上限 + 递归深度限制
  • 模板可复用：职责、系统提示、模型路由、token 上限
  • 请求级凭证继承，子代理也能用同一把 key
  • 嵌套 trace：谁派了谁、花了多少步，全都能看见

🧾工作流（workflow）

  • JSON 定义：阶段串行、阶段内步骤并行
  • 模板变量：{{input}} / {{prev}} / {{steps.x}}
  • 每个步骤独立上下文，结果自动回灌下一阶段
  • 整体走 SSE 流式推进，前端实时看进度

典型用法：研究型任务先并行侦察、再汇总成报告；重构任务先并行扫描多个模块、再统一改。

设计原则

几条不肯妥协的规矩宁可失败，也不假装成功

🚫失败关闭

沙箱后端不可用就拒绝执行，绝不静默回落到可绕过的策略层；界面、日志、快照里都写清楚现在到底是什么边界。

🔍不做空承诺

内核断网 / 强制代理 / 合作式代理分级如实标注；bwrap 没有 cgroup 配额，就把「内存/CPU 上限不生效」标出来。

🧱纵深防御

内核沙箱管「碰得到什么」，策略与审批管「要不要做」；两层各自独立，互不背锅。

🧾一切留痕

放行、拒绝、重试、审批、召回都进 trace；会话可恢复、事件可回放，出问题能复盘。
